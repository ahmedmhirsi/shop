🔐 SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════════

✅ Authentication
   • Session-based with HTTPOnly cookies
   • Bcrypt password hashing (cost 10)
   • CSRF token verification on all POST

✅ Data Protection
   • Prepared statements (100% SQL)
   • htmlspecialchars() XSS escaping
   • Input sanitization

✅ Access Control
   • Role-based (Boss vs Employee)
   • Protected routes with requireAuth()
   • Authorization checks (requireRole())

✅ HTTP Security Headers
   • X-Content-Type-Options: nosniff
   • X-Frame-Options: SAMEORIGIN
   • X-XSS-Protection: 1; mode=block

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "Page not found" when accessing URL
   Solution: Ensure .htaccess is working or access index.php directly

Issue: "Access denied" error
   Solution: Run: chmod 755 app/ public/

Issue: Database connection error
   Solution: Run: php health-check.php
   Then: Verify MySQL is running

Issue: Can't login
   Solution: Verify MySQL is running, then try default credentials

Issue: Products not showing
   Solution: Check that products are marked as "active" in database
